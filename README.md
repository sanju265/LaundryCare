# LaundryCare PHP + PostgreSQL + XML

## 1. Put the folder in XAMPP
Copy this `laundrycare` folder to:
`C:\xampp\htdocs\laundrycare`

## 2. Create PostgreSQL database
In pgAdmin 4:
- Create database: `laundrycare_db`
- Open Query Tool for that database.
- Open `database/database.sql` and execute it.

## 3. Configure PHP PostgreSQL connection
Open:
`config/database.php`

Change:
`$password = 'YOUR_POSTGRES_PASSWORD';`

to your PostgreSQL `postgres` user's password.

## 4. Check PHP PostgreSQL support
In XAMPP, Apache must use a PHP build with PDO PostgreSQL enabled. If the site says `could not find driver`, enable `pdo_pgsql` in XAMPP's PHP `php.ini` and restart Apache.

## 5. Start
Start Apache in XAMPP.

Open:
`http://localhost/laundrycare/`

## 6. Create the first admin
Run this in pgAdmin after replacing the hash with one generated by PHP.

Easy method: temporarily create `create_admin.php` with:
```php
<?php
echo password_hash('Admin@12345', PASSWORD_DEFAULT);
?>
```
Open `http://localhost/laundrycare/create_admin.php`, copy the hash, then run:
```sql
INSERT INTO admin_users(username,password_hash)
VALUES ('admin','PASTE_HASH_HERE');
```
Delete `create_admin.php` afterwards.

Login:
Username: `admin`
Password: `Admin@12345`

## Demo
1. Login.
2. Add/edit/delete customers.
3. Add/edit/delete services.
4. Create/edit/delete orders.
5. Show pgAdmin `SELECT * FROM customers;` and `SELECT * FROM orders;`.
6. Open Export XML and download the XML.
